Methodology

How a finding earns that name

Static analysis alone produces noise. Every finding in this assessment requires a sanitizer witness — a deterministic, reproducible proof artifact. No witness, no finding.

01

Static candidate

CodeQL identifies a code pattern matching a known weakness class. Retained for validation — not surfaced as a finding.

02

Sanitizer witness

The candidate is exercised under ASan and UBSan with a targeted harness. A deterministic crash or sanitizer report becomes the witness.

03

Confirmed finding

Witness confirmed → finding promoted with reproducer bundle, build configuration, and git revision. One command to reproduce.
