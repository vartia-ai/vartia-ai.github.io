02 · Executive Summary

Severe bugs in LibTIFF recur in a small set of patterns and files.

Key Findings

Across LibTIFF's historical vulnerability set, severe security bugs repeatedly fall into three families:

  • Raster-address arithmetic
  • Geometry and layout handling
  • Directory metadata state

These patterns account for the majority of severe findings in the library.

The largest hotspot appears in tools/tiffcrop.c, which contains more than half of the in-scope findings. Additional clusters appear in tif_dirread.c and tif_getimage.c.

Proof points

  • 23 of 39 in-scope findings map to tools/tiffcrop.c.
  • libtiff/tif_getimage.c contributes two paired arithmetic findings, both with automated detectors.
  • libtiff/tif_dirread.c contributes four directory-state findings, all verified by detectors tested against historical code.
  • CVE-2022-0891 has a proof-of-concept crash reproduction confirming the tiffcrop vulnerability pattern.
Prevention takeaway
The strongest prevention opportunities are:
  • Overflow checks in raster-address calculations
  • Geometry and layout validation in tiffcrop
  • Input validation for directory fields during parsing
